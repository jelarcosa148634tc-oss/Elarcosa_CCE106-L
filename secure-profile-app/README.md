## Project Description

This project is a React Native Secure Profile App that demonstrates
API authentication and secure data handling.

The application allows users to:

- Log in using a practice API account
- Securely store the access token
- Retrieve a protected user profile
- Restore an authenticated session
- Log out and delete the stored token

## Technologies Used

- React Native
- Expo
- Expo Router
- DummyJSON API
- Expo SecureStore
